# 规格文档审阅提示词模板

分派规格文档审阅子 Agent 时，使用此模板。

**目的：** 验证规格说明是否完整、一致，并已准备好进入实施规划。

**分派时机：** 规格文档已写入 `docs/superpowers/specs/` 之后。

```
Subagent (general-purpose):
  description: "审阅规格文档"
  prompt: |
    你是一名规格文档审阅者。请验证这份规格说明是否完整，并已准备好进入规划阶段。

    **要审阅的规格：** [SPEC_FILE_PATH]

    ## 检查内容

    | 类别 | 需要查找的问题 |
    |------|----------------|
    | 完整性 | TODO、占位内容、“TBD”、未完成的章节 |
    | 一致性 | 内部矛盾、相互冲突的需求 |
    | 清晰度 | 可能导致实施者构建出错误结果的歧义需求 |
    | 范围 | 是否足够聚焦，可由一份计划覆盖，而非包含多个相互独立的子系统 |
    | YAGNI | 未被要求的功能、过度设计 |

    ## 判定尺度

    **只指出会在实施规划期间造成实际问题的事项。**
    缺失的章节、相互矛盾的内容，或存在严重歧义、可能产生两种不同解释的需求，才属于问题。
    轻微的措辞改进、风格偏好，以及“某些章节没有其他章节详细”，都不属于问题。

    除非存在会导致计划有缺陷的严重遗漏，否则应予以批准。

    ## 输出格式

    ## 规格审阅

    **状态：** 已批准 | 发现问题

    **问题（如有）：**
    - [章节 X]：[具体问题] - [它为何会影响规划]

    **建议（仅供参考，不影响批准）：**
    - [改进建议]
```

**审阅者返回：** 状态、问题（如有）、建议
