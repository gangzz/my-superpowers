# Extractor 决策记录：`douyin`

## 范围

- 首期目标：用户指定的单个抖音公开作品。
- 排除范围：搜索结果采集、个人主页批量下载、直播、评论和直接转写。
- 首次探针的预期内容：视频。未来支持图文作品时，现有框架无需修改核心契约。

## 当前能力

- 浏览器能力：`visible-required`。
- Profile：使用 media-download 的本机默认持久化 Profile；它与日常 Chrome 和其他项目隔离，但与本 Skill 的其他站点共享。
- 访问状态检测：由抖音 Extractor 在作品入口链路中返回 `ready`、`login_required`、`captcha` 或 `unavailable`。
- 人工处理入口：失败 Job 使用 Extractor 决定的登录或作品入口；人工选择清晰度直接打开目标作品。
- 入口链路：完整作品链接直接进入；分享短链先通过 HTTP 重定向解析作品 ID，再规范化为已验证的 `jingxuan?modal_id=<id>` 作品入口，避免短链落地页和 `/video/<id>?previous_page=web_code_link` 入口触发安全验证。
- 目标绑定：从输入或跳转后 URL 取得作品 ID，在 `RENDER_DATA` 中找到同 ID 的目标对象，直接使用该对象内的视频 URL 生成 Manifest。
- 来源记录：只保存由作品 ID 构造的规范 URL，不保存跳转页或输入 URL 的查询参数。
- Transport 模式：目标 `RENDER_DATA` 中的合并资源和显式分离轨道都使用 `browser-session`。当前 Context 的会话材料随连续 Range 请求发送，响应以有背压的流写入磁盘。

## 已确认决策

- 生产链路从可见默认 Profile 起步；是否需要登录由当前作品入口的访问状态决定。
- `RENDER_DATA` 不提供可靠的“当前播放器资源”标记；默认按共享 Selector 的无当前标记回退规则选择合并资源，合并资源不可用时才选择视频轨和音频轨进行封装。
- 用户明确要求选择清晰度时，先打开目标作品供用户操作；关闭前读取当前视频尺寸，再提交带期望尺寸的普通 Job。
- 最终候选以实际媒体轨道检查结果为准。
- `blob:` 是页面的 MediaSource 播放地址，不能直接下载，且它本身不表示音视频分离。
- 三个 `blob:` 播放样本通过页面请求与 `ffprobe` 验证，分别为 `3840×2160 / HEVC+AAC`、`3840×2160 / HEVC+AAC`、`576×1024 / HEVC+AAC`，都是音视频合并 MP4。
- 抖音 CDN 资源不应依赖页面脚本重新 Fetch；同一 Context 会话材料的 Range 请求用于合并资源和显式分离轨道。当前实机样本已完成 `138,745,420` 字节视频轨与 `6,783,516` 字节音频轨下载、无损封装和 `ffprobe` 验证，最终文件 `145,933,975` 字节、`576×1024`、含音轨。
- 两种传输都不读取完整 `arrayBuffer`；数据逐块进入 Node 写流。最终文件通过轨道、尺寸、大小和 SHA256 检查后再提交。

## 开发与修复契约

1. 正式下载在可见模式下使用本机默认 Profile，为当前任务创建独立页面；不启动 `NetworkProbe`。
2. 在浏览器导航前解析分享短链的 HTTP 重定向和作品 ID；打开规范化作品入口并按作品 ID定位目标 `RENDER_DATA` 对象。
3. 只从该目标对象生成候选；用最终 `ffprobe` 检查区分仅视频、仅音频和音视频合并版本。
4. 开发或修复站点逻辑时，可以在外部临时现场使用 `src/dev/network-probe.mjs` 对照页面实际请求；它只提供证据，不得成为 Extractor 输入。
5. 关闭当前任务页面；队列排空后，验证 BrowserHost 已关闭 Context、Profile 已保留、锁已释放，并且没有遗留的所属进程。

登录失效或 CAPTCHA 进入可见人机接管；目标不匹配、进程归属不清或媒体连续失败进入停止状态。身份和浏览器模式由人工决策保持或变更。

## 当前验证边界

- 目标 `RENDER_DATA` 直接发现路径已用公开作品完成端到端实机验证，全程未启动 `NetworkProbe`。
- 页面内 `fetch` 对同一 CDN URL 返回 `Failed to fetch`；改用当前 Context 会话材料的 `browser-session` 后成功交付 `210,523,562` 字节、`576×1024`、时长 `889.695782` 秒且含音轨的 MP4，并完成 SHA256 检查。

## 后续资格验证

- 当前播放器清晰度是否跨页面、跨 Context 重启稳定保存在 Profile 中。
- 创作者个人主页点击链路与完整作品长链接是否生成等价 Manifest。
- 无头模式在已确认的“创作者个人主页点击作品”链路上是否行为等价。
