# 决策 0001：框架边界

状态：已于 2026-09-11 接受为 v0.1 决策。

- URL 是用户唯一必须提供的输入。
- Registry 直接选择 Extractor。
- Extractor 识别作品的实际媒体类型，并创建标准化 Manifest。
- 共享 Selector 根据内部策略选择资源版本；默认先选当前播放器使用的音视频合并资源，没有当前标记时回退到最低合并资源，合并资源不可用时才封装分离轨道。
- 图文作品默认返回完整且有序的图片集合。
- 访问要求属于 Manifest 中的资源；传输实现保持共享。
- 浏览器 Extractor 从可见模式起步。无头模式是每个 Extractor 分别用证据验证的能力。
- 每个 Extractor 在 `docs/extractors/` 下维护持续演进的决策记录和探针契约。
- 运行状态放在已安装 Skill 之外，由共享运行时执行有边界的清理。
