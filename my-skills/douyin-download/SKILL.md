# 抖音单视频下载

使用随附脚本调用固定版本的 jiji262/douyin-downloader。不要仅凭上游退出码、作品页可访问或文件存在声称下载成功。

## 运行

所有相对路径按本 Skill 目录解析。首次运行或依赖缺失时：

```sh
python3 scripts/setup.py
```

安装需要 GitHub／Python 包源网络访问，运行需要本机 `ffprobe`（随 ffmpeg 安装）。初始化只在 Skill 的 `.runtime/` 中创建上游 checkout 和 Python 虚拟环境，不更新用户全局 Python。固定版本及选型证据见 [upstream.md](references/upstream.md)。不自动更新 main；升级后需要重新试跑。

```sh
python3 scripts/download.py 'https://www.douyin.com/video/作品数字ID' --output '/绝对路径/输出目录'
```

一次只处理一个指定作品；多个明确链接逐条运行。仅支持标准单视频链接或 `v.douyin.com`／`v.iesdouyin.com` 短链，解析后的目标仍须是单视频。不要将主页链接当成用户授权的全账号下载。

输出 JSON 为 `success` 时包含实际路径、字节数、SHA256、时长与音视频流；文件名带作品 ID 和本次运行编号，避免覆盖旧文件。随附 `download-*.json` 保存来源与上游版本。报告只证明下载和媒体探测通过，不代表内容已观看、完整解码、效果属实或 ASR 已完成。

## 网络与登录

- 默认不启动浏览器、不读取浏览器 Cookie、不加载项目现有配置。没有登录材料时先试指定作品一次。
- 需要代理时可显式加 `--proxy`，不要将含密码的代理地址贴到聊天或写进共享文档。
- 用户提供或授权使用某个本地 Cookie 文件后，使用 `--cookies-file '/本地私有文件.json'`；格式是 Cookie 名到字符串值的 JSON 对象。不要向聊天索要原始 Cookie，不自动扫描其他配置或账号。Cookie 仅在进程内使用，不写进结果。
- `blocked` 或非零退出表示未完成。平台校验、登录失效或验证码不是加长重试就能解决；说明阻塞原因，获取适用的登录材料／文件后再继续。不要自动打开浏览器或处理验证码。
- 工具关闭了上游浏览器回退、评论采集、通知、云端转写与附加文件选项；本 Skill 不上传媒体至转写服务。

## 交付

提供已验证视频的本地链接和来源记录；逐条区分成功／失败。ASR 是后续动作，不将作品简介、字幕索引或机器摘要冒充从该视频识别的逐字稿。

调试先检查状态 JSON。上游日志可能包含带签名的 URL 或请求信息，包装脚本不向聊天透传原始日志。初始现场验证记录见 [validation.md](references/validation.md)；不能把结构校验通过解释为平台下载已打通。
