## 调用方式

- 仅手工调用。
- `agents/openai.yaml` 设置 `allow_implicit_invocation: false`。
- Agent 主动建议时必须说明具体问题、预期收益和主要成本，并等待用户决定。

## 验收

### 应使用

1. 用户显式调用，且手头有一批具体的评审意见（来自用户、/code-review、外部评审者或 PR 评论）等待处理。

### 不应使用

1. 没有具体评审意见，只是泛泛讨论代码质量。
2. 用户未显式调用，且 Agent 无法说明具体问题与成本收益。
